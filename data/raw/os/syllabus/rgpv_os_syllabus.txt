UNIT 3 — CPU Scheduling and Memory Management
================================================================================

CPU Scheduling:
- Process Concept — process definition, PCB (Process Control Block)
- Scheduling Concepts — CPU-I/O burst cycle
- Types of Schedulers — Long-term, Short-term, Medium-term
- Process State Diagram — New, Ready, Running, Waiting, Terminated

Scheduling Algorithms:
- FCFS (First Come First Serve)
- SJF (Shortest Job First) — preemptive and non-preemptive
- Round Robin
- Priority Scheduling — preemptive and non-preemptive
- Multilevel Queue Scheduling
- Multilevel Feedback Queue

Algorithm Evaluation:
- Criteria: CPU utilization, throughput, turnaround time, waiting time, response time
- Deterministic modeling, queueing models

System Calls for Process Management

Multiple Processor Scheduling

Concept of Threads:
- Single-threaded vs multi-threaded processes
- Benefits of threads
- User-level threads vs kernel-level threads

Memory Management:
- Different Memory Management Techniques
- Partitioning (Fixed and Variable)
- Swapping
- Segmentation
- Paging — page table, page size, internal fragmentation
- Paged Segmentation
- Comparison of these techniques

Techniques for Supporting Execution of Large Programs:
- Overlay
- Dynamic Linking and Loading

Virtual Memory:
- Concept of Virtual Memory
- Implementation by Demand Paging
- Page Fault handling
- Page Replacement Algorithms — FIFO, Optimal, LRU, LFU
- Thrashing — causes and solutions
- Working Set Model

UNIT 4 — I/O Management, Concurrent Processes, and Deadlocks
================================================================================

Input / Output:
- Principles of I/O
- Programming I/O
- I/O Problems
- Asynchronous Operations
- Speed Gap between CPU and I/O devices
- Format Conversion
- I/O Interfaces

Types of I/O:
- Programme Controlled I/O (Polling)
- Interrupt Driven I/O
- DMA (Direct Memory Access)
- Concurrent I/O

Concurrent Processes:
- Real and Virtual Concurrency
- Mutual Exclusion — definition and requirements
- Synchronization
- Inter-Process Communication (IPC) — shared memory, message passing

Critical Section Problem:
- Definition and requirements (Mutual Exclusion, Progress, Bounded Waiting)
- Peterson's Solution
- Hardware solutions — TestAndSet, Compare-and-Swap

Semaphores:
- Binary Semaphore (Mutex)
- Counting Semaphore
- WAIT (P) and SIGNAL (V) Operations
- Implementation of semaphores
- Classical problems — Producer-Consumer, Reader-Writer, Dining Philosophers

Deadlocks:
- Deadlock Problem — definition and example
- Characterization of Deadlock:
  - Necessary Conditions: Mutual Exclusion, Hold and Wait, No Preemption, Circular Wait
  - Resource Allocation Graph
- Deadlock Prevention — negating each necessary condition
- Deadlock Avoidance — Banker's Algorithm (Resource Allocation Graph Algorithm)
- Deadlock Detection — detection algorithm, resource allocation graph
- Deadlock Recovery — process termination, resource preemption
